Ben's main languages are Python, TypeScript, JavaScript and SQL.

On the data side, his working set is PostgreSQL, SQL Server with T-SQL including stored
procedures, PySpark, REST APIs, ETL, and data warehousing. On the application side, Node.js,
Express and React, with HTML, CSS and Tailwind.

SQL and Python are the two he would claim genuine depth in. Most of the work at Visa, Russell
McVeagh and Technology Investment Network ran through one or both of them. TypeScript sits close
behind, from the AWS CDK infrastructure at Visa, the Next.js work on Snip, and this personal
site.

His testing practice is pytest on the Python side and Jest or Vitest on the JavaScript side, and
he treats it as part of writing the code rather than a separate phase afterwards. The question
answering service producing this answer was built test-first, with each test written and watched
to fail before the implementation that satisfies it.
